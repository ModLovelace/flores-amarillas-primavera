# 🌻 Celebraciones & Regalos Virtuales · Experiencia Multitemática

> 🌐 **Sitio Web en Vivo:** [https://regala-flores-amarillas.vercel.app](https://regala-flores-amarillas.vercel.app)

Una plataforma interactiva, estética y emocional inspirada en las mejores tendencias visuales de **Pinterest** y optimizada para el marketing viral en **TikTok**, **Instagram** y **WhatsApp**. 

Permite a cualquier persona crear y enviar detalles virtuales inolvidables para las ocasiones más importantes del año: regalar flores amarillas de primavera, festejar cumpleaños con velas y confeti, celebrar graduaciones y metas profesionales, o conmemorar aniversarios y lazos de amor/amistad eterna.

---

## 🎨 4 Ocasiones & Temas Especiales

La plataforma incluye un selector temático instantáneo (barra horizontal estilo Pinterest y modal visual 2x2) que transforma completamente la paleta de colores, partículas interactivas, piezas centrales ilustradas, música ambiental sintetizada y tarjetas para presumir:

| Ocasión | Pieza Central | Partículas | Banda Sonora (Web Audio API) | Viral Tagline |
| :--- | :--- | :--- | :--- | :--- |
| 🌻 **Flores Amarillas & Primavera** | Ramo de Girasoles, Margaritas y Rosas Doradas | Pétalos de Flor Dorados | Vals de Primavera en Celesta & Campanas | `#FloresAmarillas #21DeSeptiembre` |
| 🎂 **Feliz Cumpleaños** | Pastel Gourmet con Velas Encendidas & Bengalas | Confeti Festivo Multicolor | Melodía Dulce de Cumpleaños & Campanitas | `#FelizCumpleaños #BirthdayGirl` |
| 🎓 **Logro Profesional** | Corona de Laurel Dorada & Trofeo de la Victoria | Destellos Dorados & Champaña | Fanfarria Triunfal & Acordes de Éxito | `#LogroAlcanzado #Graduación` |
| 💖 **Aniversario & Amor** | Ramo Romántico de Rosas Aterciopeladas & Peonías | Lluvia de Corazones Flotantes | Acordes Románticos & Arpa de Cristal | `#FelizAniversario #AmorEterno` |

## ✨ Características Principales

- 🌸 **Piezas Centrales Ilustradas con 4 Etapas de Floración / Interacción**:
  - Ramo de flores amarillas floreciendo brote a brote.
  - Pastel de cumpleaños encendiendo velas, chispas y deseos.
  - Corona de laurel y trofeo puliéndose hasta resplandecer en oro puro.
  - Ramo de rosas rojas y peonías abriéndose con destellos y amor eterno.
- 🎶 **Banda Sonora Dinámica Sintetizada en Tiempo Real (Web Audio API)**:
  - 100% libre de copyright y sin tiempos de carga de archivos de audio pesados.
  - Melodías y armonías exclusivas diseñadas para cada una de las 4 ocasiones.
  - Reproductor flotante estilo disco de vinilo retro con control de reproducción y cambio de pistas.
- 📸 **✨ Creador de Tarjetas para Presumir en Redes (TikTok & Instagram)**:
  - **📱 Historia / TikTok (9:16 Pantalla Completa)**: Diseñado con zonas seguras para Stories y TikTok. Incluye stickers de audio de tendencia (`🎵 Sonido de Tendencia`), fecha, dedicatoria y hashtags virales de la ocasión.
  - **🖼️ Post / Feed (1:1 Cuadrado Clásico)**: Formato ideal para feed, carruseles de Instagram o estados de WhatsApp.
  - **3 Estilos Estéticos**: *Paleta Ocasión*, *🌙 Modo Aesthetic Noche* y *🌸 Romance/Elegance*.
  - **Compartir Nativo**: Web Share API para publicar directo a Stories o chats desde el móvil, descarga instantánea en HD (.PNG) y botón de copiado rápido al portapapeles.
- 💌 **Carta Secreta con Sello de Cera Vintage Interactivo**:
  - Sobre realista con textura artesanal y sello de cera temático (oro, rubí, esmeralda o rosa).
  - Al hacer clic, el sobre se desella suavemente revelando una dedicatoria personalizada con tipografía manuscrita y firma del remitente.
- 🎈 **Física de Partículas Reactivas al Cursor & Pantalla Táctil**:
  - Lluvia continua de pétalos dorados, confeti pastel, destellos brillantes o corazones flotantes que responden al movimiento del cursor o al toque táctil.
- 🔗 **Personalizador de Enlaces & Compartir por WhatsApp**:
  - Generador de enlaces único: `?theme=...&to=Nombre&from=TuNombre&msg=Mensaje&date=Fecha`.
  - Botón para compartir directo por WhatsApp con copy optimizado y enlaces persistentes.

## 🚀 Cómo Ejecutar en Local

```bash
# 1. Clonar el repositorio
git clone https://github.com/ModLovelace/flores-amarillas-primavera.git
cd flores-amarillas-primavera

# 2. Instalar dependencias
npm install

# 3. Iniciar el servidor de desarrollo Vite
npm run dev

# 4. Compilar para producción
npm run build
```

## 🛠️ Stack Tecnológico

- **React 18** + **Vite**
- **Tailwind CSS** (animaciones CSS personalizadas, sombras difusas, paletas dinámicas)
- **html-to-image** (generación y captura de tarjetas HD en el navegador)
- **Web Audio API** (motor de síntesis de audio procedural en el cliente)
- **Lucide React** (iconografía vectorial moderna)
- **Canvas Confetti**
- **Vercel** (despliegue edge global continuo)
